Hexchess plays with an engine compiled to WebAssembly (hexchess.wasm). Browsers only load it when the page is served over http(s) — opening web/index.html straight from disk does not work.

  1. Run npm run serve in the project folder and open http://localhost:8080/, or
  2. open the single-file build dist/hexchess.html, which embeds the engine and also works from disk (create it with npm run build).
